Student Attrition Analysis Dashboard

📊 Project Overview

This project focuses on analyzing student attrition using Microsoft Power BI to identify patterns, explore key factors, and support data-driven decision-making.

🎯 Project Objectives

- Analyze student attrition patterns.
- Explore academic and student-life indicators.
- Identify key insights and trends.
- Present findings through interactive dashboards.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning and Transformation

📈 Dashboard Pages

- Overview: A summary of the main KPIs and key findings.
- Academic Analysis: Analysis of academic indicators and their relationship with student attrition.
- Student Life Analysis: Exploration of student-life factors and related patterns.

📥 How to Use

1. Download the ".pbix" file from the "Dashboard" folder.
2. Install Microsoft Power BI Desktop.
3. Open the downloaded file using Power BI Desktop.
4. Explore the report pages and interact with the available filters and slicers.

📁 Repository Structure

- "Dashboard/" — Power BI report file.
- "Screenshots/" — Dashboard screenshots.
- "Dataset/" — Dataset, if publicly shareable.
